# 工时核对

把工时、薪资与工资条差额核对清楚。

工时核对面向倒班、小时工、计件工，以及需要自行核算工资的个人用户：按日期记录班次、工时、计件、补贴和扣款，使用自己的计薪规则计算期望薪资，再输入实发金额查看差额来源。

## 产品原则

- 工时与工资数据默认只保存在设备上
- 无广告、无第三方分析、不跨 App 追踪
- 备份、恢复、CSV 导入与导出始终免费
- 高级功能通过 Apple App Store 内购解锁

计算结果仅供个人工时与薪资核对参考，不构成工资发放、税务、社保或劳动法律意见。

本仓库托管产品的静态介绍、隐私政策与支持页面，使用 GitHub Pages 发布。
